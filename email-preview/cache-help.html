Íslenska — efni: „Vandræði með innskráningu á Stórkaup.is? Prófaðu þetta“

Halló Jón,

Takk fyrir að heyra í okkur. Þegar við uppfærum vefinn á vafrinn það stundum til að geyma gamlar upplýsingar, sem getur truflað innskráningu eða vöruskoðun.

Það er yfirleitt fljótlegt að leysa þetta með þessum skrefum:

  1. Lokaðu vafranum alveg (ekki bara flipanum).
  2. Opnaðu vafrann aftur.
  3. Farðu á www.storkaup.is og reyndu aftur.

Ef það dugir ekki til:

  • Chrome / Edge: Ctrl + Shift + Delete → hakaðu við „Skyndiminni“ og „Vafrakökur“ → Hreinsa gögn
  • Firefox: Ctrl + Shift + Delete → hakaðu við „Skyndiminni“ → Hreinsa
  • Mac (allir vafrar): ⌘ + Shift + Delete

Að þessu loknu: Lokaðu vafranum, opnaðu hann aftur og reyndu að skrá þig inn.

Ef þetta virkar samt ekki máttu endilega láta okkur vita svo við getum skoðað málið nánar með þér.

English — subject: “Having trouble logging in to Storkaup.is? Try this first”

Hi John,

Thank you for contacting us. When we update the website, your browser sometimes stores old information, which can interfere with logging in or viewing products.

This can usually be resolved quickly with these steps:

  1. Close your browser completely (not just the tab).
  2. Reopen the browser.
  3. Go to www.storkaup.is and try again.

If that doesn't work:

  • Chrome / Edge: Ctrl + Shift + Delete → tick “Cached images and files” and “Cookies and other site data” → Clear data
  • Firefox: Ctrl + Shift + Delete → tick “Cache” → Clear Now
  • Mac (all browsers): ⌘ + Shift + Delete

After doing this: Close the browser, reopen it, and try to log in.

If it still doesn't work, please let us know so we can look into it further with you.
